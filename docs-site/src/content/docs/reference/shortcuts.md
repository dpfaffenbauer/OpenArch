title: "Keyboard shortcuts"

OpenArch has Arc's keyboard shortcuts. Every command with a shortcut is also
in the menu bar, so the menus are a quick way to look one up. You can give
any menu command a shortcut of your own in **Settings › Tastatur** (keyboard).

## They win over the page

OpenArch's own shortcuts take precedence over the page, as in Arc: a website
cannot take <kbd>⌘T</kbd>, <kbd>⌘L</kbd> or <kbd>⌃Tab</kbd> for itself, and
Chrome's own meaning of a key never applies (<kbd>⌥⌘→</kbd> changes spaces,
as in Arc, not tabs, as in Chrome). This holds for every OpenArch command
with <kbd>⌘</kbd> or <kbd>⌃</kbd>.

The editing shortcuts (<kbd>⌘C</kbd>, <kbd>⌘V</kbd>, <kbd>⌘Z</kbd> …) and
the system's window and app shortcuts (<kbd>⌘M</kbd>, <kbd>⌘H</kbd> …) are
not OpenArch's own and work as in any Mac app.

## Tabs

| Keys | Command | What it does |
| --- | --- | --- |
| <kbd>⌘T</kbd> | **Neuer Tab** | Opens the [command bar](/browsing/command-bar/) for a new tab. |
| <kbd>⌘L</kbd> | **Adresse öffnen …** | Opens the command bar on the current address. |
| <kbd>⌘W</kbd> | **Tab schließen** | Closes the tab. A today tab goes to the archive; a pinned tab or favorite only closes its page and stays in the sidebar. In DevTools, closes the DevTools. |
| <kbd>⇧⌘T</kbd> | **Geschlossenen Tab wieder öffnen** | Brings back the last closed tab, or the last closed window if that closed later. |
| <kbd>⌘D</kbd> | **Anheften / Lösen** | Pins a today tab, or unpins a pinned one. |
| <kbd>⇧⌘K</kbd> | **Heute aufräumen** | Sends all of the space's today tabs to the archive. |
| <kbd>⌥⌘↓</kbd> or <kbd>⇧⌘]</kbd> | **Nächster Tab** | The next tab down the sidebar. |
| <kbd>⌥⌘↑</kbd> or <kbd>⇧⌘[</kbd> | **Vorheriger Tab** | The tab above. |
| <kbd>⌃Tab</kbd> | **Zuletzt benutzter Tab** | The tab switcher; see [below](#the-tab-switcher). |
| <kbd>⌃⇧Tab</kbd> | **Zuletzt benutzter Tab rückwärts** | The tab switcher, going back. |
| <kbd>⌘1</kbd> … <kbd>⌘8</kbd> | **Tab 1** … **Tab 8** | The first to eighth tab in the sidebar: favorites first, then the pinned tabs in open folders, then today's tabs. |
| <kbd>⌘9</kbd> | **Letzter Tab** | The last tab in the sidebar. |
| – | **Zu Favoriten hinzufügen** | Makes the tab a favorite. |
| – | **Tab duplizieren** | Opens the same page in a new tab. |

## The tab switcher

Hold <kbd>⌃</kbd> and press <kbd>Tab</kbd>: the tabs you used most recently
(up to eight) appear in a row over the page, each with a picture of its page,
and the tab you used before this one is marked.

- Press <kbd>Tab</kbd> again to move along, <kbd>⇧Tab</kbd> to go back, or use
  the arrow keys.
- Let go of <kbd>⌃</kbd>, or press <kbd>↩</kbd>, to go to the marked tab.
- <kbd>⎋</kbd> closes the switcher and stays where you are.

## In the command bar

| Keys | What it does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through the results. |
| <kbd>↩</kbd> | Opens the marked result. |
| <kbd>→</kbd> | Keeps the address the bar completed as you typed. |
| <kbd>⌫</kbd> | Drops the completion. In a site search with nothing typed, leaves the site. |
| <kbd>Tab</kbd> | After a site's keyword or name (yt, gh, w …), searches that site. Otherwise moves to the next result. |
| <kbd>⎋</kbd> | Back to what you typed, or closes the bar. |

## Mouse and trackpad

| Gesture | What it does |
| --- | --- |
| Swipe sideways over the sidebar (two fingers on a trackpad, one on a Magic Mouse) | Changes spaces. Past the first space, opens the library; swiping back closes it. |
| <kbd>⌘</kbd>-click a link on a page | Opens it as a new tab in the background. |
| <kbd>⌘</kbd>-click a tab or folder in the sidebar | Loads its pages in the background, so they are ready when you get to them. |
| Double-click the space's name in the sidebar | Edits the space. |
| Move the pointer to the window's left edge | Brings back a hidden sidebar over the page. |
| Drag the sidebar's edge far to the left | Hides the sidebar. |

## Change a shortcut

**Settings › Tastatur** lists every command in the menu bar, grouped by menu,
with its shortcut, or **–** for none. **Befehl suchen** (search command)
filters the list.

1. Click the shortcut beside a command. It reads **Tasten drücken …**.
2. Press the new keys. A shortcut needs <kbd>⌘</kbd> or <kbd>⌃</kbd>, with
   <kbd>⌥</kbd> and <kbd>⇧</kbd> as you like.

While it records:

- <kbd>⌫</kbd> removes the command's shortcut.
- <kbd>⎋</kbd> stops without a change.
- A shortcut another command has moves to this one; the other command is
  left without one, and OpenArch tells you which it was.

A shortcut you changed shows in the accent color, with a button beside it to
go back to the original. **Alle zurücksetzen** puts back every shortcut.
A new shortcut for an OpenArch command wins over the page just as the
original one did.

:::note
A few commands have a second shortcut that the list does not show:
<kbd>⌥⌘B</kbd> for the library, <kbd>⇧⌘]</kbd> and <kbd>⇧⌘[</kbd> for the
next and previous tab, and <kbd>⌘=</kbd> to zoom in. They keep working when
you change the first one.
:::
